Un CFO virtuel pour les PME d'Afrique de l'Ouest

MoneXa est conçu pour le Défi 2 (application mobile) de l'ESIG Tech Arena 2026, avec un backend Django et une app Flutter offline-first. Cette vitrine web reprend le template Stocker (HTML Codex) pour le back-office comptable et la démonstration jury.

Rigueur financière : pas de FloatField, références opérateurs uniques, écritures en transaction.atomic(), journal d'audit hash-chainé.

Inclusion : français, et langues locales prévues (Ewé, Kabyé) sur mobile.

Stack
  • Django 4.2 + DRF
  • PostgreSQL 16
  • Flutter + BLoC
  • Vision LLM + TresorIA
